# BARTS 홈페이지 관리 안내

평소에는 **관리자 화면(Pages CMS)** 에서 칸만 채우면 됩니다. 코드는 볼 필요가 없습니다.

---

## A. 처음 한 번만 하는 설정 (약 15분)

### 1단계: 홈페이지 파일을 GitHub에 올리기
1. https://github.com 에 가입하고 로그인합니다. 연구실 공용 계정을 추천합니다.
2. 오른쪽 위 **＋ → New repository**를 누릅니다.
   - Repository name: `barts`
   - **Public**을 선택한 뒤 **Create repository**를 누릅니다.
3. 다음 화면에서 **uploading an existing file** 링크를 누릅니다.
4. 압축을 푼 `barts` 폴더를 열고, **숨김 파일까지 보이게 한 뒤** 안의 내용을 전부 선택해서 끌어다 놓습니다.
   - Mac: Finder에서 **Cmd + Shift + .(마침표)** 를 누르면 `.pages.yml` 같은 숨김 파일이 보입니다.
   - Windows: 탐색기의 **보기 → 숨긴 항목**을 체크합니다.
   - ⚠️ `.pages.yml` 파일이 빠지면 관리자 화면이 동작하지 않습니다.
5. 아래쪽 **Commit changes**를 누릅니다.

### 2단계: 홈페이지 공개하기
1. 저장소의 **Settings → Pages**로 갑니다.
2. Branch를 **main**, 폴더를 **/(root)** 로 고르고 **Save**를 누릅니다.
3. 1~2분 뒤 `https://계정이름.github.io/barts/` 에서 홈페이지가 열립니다.

### 3단계: 관리자 화면 연결하기
1. https://app.pagescms.org 에 접속해서 **Sign in with GitHub**로 로그인합니다.
2. 처음이면 **Install the GitHub app**을 누르고, `barts` 저장소를 선택해 설치합니다.
3. 목록에서 `barts`를 누르면 관리자 화면이 열립니다. 🎉

### 4단계: 교수님과 학생들 초대하기 (GitHub 계정이 없어도 됩니다)
1. 관리자 화면 왼쪽 아래 **Collaborators**를 누릅니다.
2. 교수님이나 학생의 **이메일 주소**를 넣고 초대합니다.
3. 초대받은 사람은 이메일 링크로 들어와서 바로 수정할 수 있습니다.

### (선택) 개인 도메인 연결 (예: sunghoo.kim)
1. 도메인을 산 곳(가비아, Cloudflare 등)의 DNS 설정에서 다음을 추가합니다.
   - `www` → **CNAME** → `계정이름.github.io`
   - 루트(@) 도메인도 쓰려면 **A 레코드** 4개: `185.199.108.153`, `185.199.109.153`, `185.199.110.153`, `185.199.111.153`
2. GitHub 저장소의 **Settings → Pages → Custom domain**에 `www.sunghoo.kim`을 넣고 **Save**를 누릅니다.
3. 몇 시간 뒤 **Enforce HTTPS**를 체크합니다.

## B. 평소 사용법

**app.pagescms.org에 로그인하고 `barts`를 누르면** 왼쪽에 메뉴가 보입니다.

| 메뉴 | 여기서 하는 일 |
|---|---|
| 📰 소식 · 갤러리 | 학회, 수상, 세미나 소식 추가. **사진을 넣으면 갤러리에도 자동으로 올라갑니다** |
| 📄 논문 | 새 논문 추가 |
| 👥 구성원 | 학생 추가, 졸업 처리, 교수님 정보 수정 |
| 🖼️ 갤러리 추가 사진 | 단체사진처럼 소식과 상관없는 사진 |
| ⚙️ 연구실 소개 · 연구 분야 · 모집 | 소개글, 연구 분야, 모집 문구 |

### 새 소식 올리기
1. **📰 소식 · 갤러리**를 누릅니다.
2. 맨 아래 **＋ Add an item**를 누릅니다.
3. 연도, 날짜, 분류, 제목을 채우고, 사진이 있으면 끌어다 놓습니다.
4. 새 항목의 손잡이(⋮⋮)를 **맨 위로 끌어 올립니다.** 맨 위에 있는 소식이 최신 소식으로 표시됩니다.
5. 오른쪽 위 **Save**를 누르면 **1분 뒤 홈페이지에 반영**됩니다.

### 새 논문 올리기
**📄 논문 → 저널 논문 → ＋ Add an item** → 연도, 저자, 제목, 저널을 입력하고 맨 위로 끌어 올린 뒤 **Save**를 누릅니다.

### 학생 추가 / 졸업 처리
- **추가:** 👥 구성원 → 연구원 → ＋ Add an item → 이름을 쓰고 **과정**(박사과정, 석사과정 등)을 고른 뒤 사진을 올리고 Save를 누릅니다. 홈페이지에서 과정별 그룹으로 자동 정리됩니다.
- **졸업:** 연구원 목록에서 그 학생을 지우고(🗑), 졸업생에 새로 추가합니다.

### 실수했을 때
GitHub 저장소에서 바뀐 파일을 열고 **History**를 누르면 예전 버전을 볼 수 있고, 그대로 되돌릴 수 있습니다. 홈페이지가 망가질 걱정은 하지 않으셔도 됩니다.

## C. 꼭 해야 할 일: 옛 구글 사이트 사진 옮기기

지금 소식에 있는 사진 12장은 **구글 사이트에 있는 사진을 빌려 쓰는 중**입니다. 구글 사이트를 닫기 전에 다음을 해 주세요.
1. 구글 사이트에서 각 사진을 저장합니다.
2. 관리자 화면 📰 소식에서 해당 항목을 열고 **사진** 칸에 올린 다음, **외부 사진 주소** 칸을 지우고 Save를 누릅니다.

## D. 디자인 바꾸기

- **색깔:** GitHub 저장소의 `assets/style.css` 파일 맨 위 `:root { ... }` 안에 있는 색상 코드(`#0e1b36` 등)만 바꾸면 사이트 전체에 적용됩니다.
- **그 외(레이아웃, 애니메이션, 메뉴 등):** Claude에게 말로 요청한 뒤, 받은 파일을 GitHub에 덮어쓰기로 올리면 됩니다.

## 파일 구조 (참고용)
```
.pages.yml          관리자 화면 설정 (숨김 파일, 지우지 마세요)
index.html          페이지 뼈대
assets/style.css    색상·글꼴
assets/hero.js      상단 야경·열차·자동차 애니메이션
assets/app.js       내용을 읽어 화면에 그리는 코드
content/*.yml       ★ 실제 내용 (관리자 화면이 이 파일들을 고칩니다)
images/             사진 (관리자 화면에서 올린 사진이 여기 저장됩니다)
```
